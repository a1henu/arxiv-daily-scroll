# Introducing the Generative Application Firewall (GAF)
**arXiv**：[2601.15824v1](https://arxiv.org/abs/2601.15824) · [PDF](https://arxiv.org/pdf/2601.15824.pdf)  
**作者**：Joan Vendrell Farreny, Martí Jordà Roca, Miquel Cornudella Gaya, Rodrigo Fernández Baón, Víctor García Martínez, Eduard Camacho Sucarrat, Alessandro Pignati  

**一句话要点**：提出生成式应用防火墙（GAF）以统一保护LLM应用的安全架构层。

**关键词**：生成式应用防火墙, LLM应用安全, 统一防御架构, 自主代理安全, 工具交互保护

## 3 点简述
- 核心问题：现有LLM应用防御措施（如提示过滤器、护栏、数据掩码）分散，缺乏统一协调。
- 方法要点：GAF整合这些防御措施为单一执行点，类似WAF协调网络流量防御，并覆盖自主代理及其工具交互。
- 实验或效果：未知。

## 摘要（原文）

> This paper introduces the Generative Application Firewall (GAF), a new architectural layer for securing LLM applications. Existing defenses -- prompt filters, guardrails, and data-masking -- remain fragmented; GAF unifies them into a single enforcement point, much like a WAF coordinates defenses for web traffic, while also covering autonomous agents and their tool interactions.
